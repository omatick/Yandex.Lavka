# Яндекс Лавка — КБЖУ в каталоге (Tampermonkey)

Пользовательский скрипт для расширения **Tampermonkey**, который автоматически подгружает и отображает показатели КБЖУ (калории, белки, жиры, углеводы) продуктов непосредственно на карточках товаров в каталоге Яндекс Лавки (в разделах готовой еды, стритфуда и др.). Больше не нужно заходить внутрь каждого товара, чтобы узнать его пищевую ценность!

---

## Ключевые особенности

* 🚀 **Отображение КБЖУ в каталоге**: Показывает калорийность, белки, жиры и углеводы прямо под ценой товара.
* 📏 **Автоматическая адаптация размера**: Данные выводятся в супер-компактном виде (без лишних пробелов, с округлением калорий, например `🔥181` и `Б5.5`), благодаря чему скрипт **не раздвигает карточки товаров по горизонтали** и не приводит к автоматическому закрытию боковой панели корзины.
* ✨ **Умная подсветка (Highlighting)**: Подсвечивает товары яркой рамкой, если они соответствуют заданным вами диапазонам (по калориям, белкам, жирам и углеводам), с выбором режима "На 100 грамм" или "На блюдо".
* 🛡️ **Защита от блокировок Яндекса (Anti-Ban)**:
  * **Асинхронная очередь (Rate Limiter)**: Фоновые запросы отправляются последовательно с регулируемой паузой (по умолчанию 1000 мс).
  * **Viewport-only сканирование (IntersectionObserver)**: Запросы отправляются только для тех карточек товаров, которые попали в видимую область экрана пользователя (+100px запаса для предзагрузки).
* 💾 **Умное кэширование**: Результаты сохраняются в `localStorage` вашего браузера. При повторном скролле или перелистывании страниц данные подгружаются мгновенно и без сетевых запросов. Время жизни кэша настраивается (по умолчанию 7 дней).
* ⚙️ **Встроенные настройки**: Желтая кнопка-шестеренка в левом нижнем углу экрана открывает форму, где вы можете настроить задержку, срок хранения кэша, включить/выключить отображение «на 100 г» или «на порцию», а также сбросить кэш.
* 🌓 **Адаптация под темную/светлую тему**: Цвета плашки КБЖУ используют нативные CSS-переменные Яндекс Лавки (`--theme-bg-minor`, `--theme-text-minor`), поэтому плашка идеально смотрится на любой теме оформления.
* ♻️ **Автообновление**: Скрипт поддерживает функцию автоматического обновления из GitHub-репозитория.

## Настройки КБЖУ

При нажатии на шестеренку в левом нижнем углу открывается панель:

1. **Задержка запросов (мс)**: Пауза между фоновыми запросами карточек для защиты от капчи (от 0 до 10000 мс).
2. **Время кэша (дней)**: Период, по истечении которого КБЖУ будет загружено заново для обновления данных (от 0 до 1000 дней). Если указать 0, кэширование будет отключено.
3. **Показывать на 100 г**: Отображает строку с пищевой ценностью на 100 грамм продукта.
4. **Показывать на порцию**: Отображает строку с пищевой ценностью на все блюдо (если вес порции указан в карточке товара).
5. **Подсветка товаров по КБЖУ**: Включает режим выделения карточек, подходящих под критерии. Можно выбрать режим ("На 100 грамм" или "На блюдо") и задать диапазоны `от` и `до` для каждого макронутриента. Если не задано "от", считается что от 0. Если не задано "до", верхний предел не учитывается.
6. **Сбросить кэш**: Очищает сохраненные данные КБЖУ, позволяя перезагрузить их.

## Инструкция по установке

1. Установите расширение **Tampermonkey** для вашего браузера (доступно для Chrome, Firefox, Safari, Edge, Opera).
2. Создайте новый скрипт в Tampermonkey (нажмите на иконку расширения -> *Создать новый скрипт...*).
3. Удалите весь шаблонный код в открывшемся редакторе.
4. Скопируйте код из файла [tampermonkey_script.js](tampermonkey_script.js) и вставьте его в редактор Tampermonkey.
5. Сохраните скрипт (Ctrl + S).
6. Перейдите в каталог Яндекс Лавки (например, в раздел [Готовая еда](https://lavka.yandex.ru/catalog/grocery/category/all_ready_meals) или [Горячий стритфуд](https://lavka.yandex.ru/catalog/grocery/category/hot_streetfood)). Скрипт начнет работу автоматически!
